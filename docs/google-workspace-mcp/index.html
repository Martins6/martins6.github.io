Google Workspace MCP

A local Model Context Protocol server for Gmail, Google Calendar and Google Drive.

Google Workspace MCP is an open-source, single-file MCP server that lets an AI agent read and act on a user's own Google Workspace data through the Google Workspace CLI (gws). It runs entirely on the user's machine over stdio, uses the user's own OAuth client, and stores OAuth refresh tokens locally.

What it does

  • Calendar: list calendars, upcoming agenda, create and delete events.
  • Gmail: search and read messages, send mail or save drafts.
  • Drive: search files, upload files into a single configured folder.
  • Multiple accounts, each with an enforced capability list.

Source code

The source, documentation and security notes are at github.com/Martins6/google-workspace-mcp.

Privacy

The app accesses Google user data only when the user invokes a tool, keeps OAuth credentials on the local machine, and sends no telemetry. Read the full Privacy Policy.
