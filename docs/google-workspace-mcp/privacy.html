Privacy Policy

Google Workspace MCP · Last updated 9 November 2026

Google Workspace MCP ("the app") is an open-source, local Model Context Protocol server that lets a user's AI agent access the user's own Gmail, Google Calendar and Google Drive data. This policy explains what data the app accesses, how it is used and stored, and how you can revoke access.

1. Google user data the app accesses

Only after you authorize the app with your own Google Cloud OAuth client, and only when a tool is invoked, the app may access:

  • Gmail: message metadata and content, and the ability to create drafts or send messages, according to the scopes you grant.
  • Google Calendar: calendar lists and events, and the ability to create or delete events, according to the scopes you grant.
  • Google Drive: file metadata and content, and the ability to create files in a configured folder, according to the scopes you grant.

2. How the data is used

Data is used solely to perform the action you or your agent requested (for example, searching mail, reading an event, sending a draft, or uploading a file). The app does not use Google user data for advertising, profiling, or any purpose unrelated to the requested action.

3. Storage and retention

  • OAuth credentials (including a refresh token) are stored only on your local machine, in files readable only by your user account (~/.config/gws/accounts/…, mode 600).
  • The app itself does not store message bodies, calendar contents or Drive files. Tool results are returned to the calling AI client, whose own retention rules apply.
  • Credentials remain until you delete them or revoke the app's access. Revoking access invalidates the refresh token.

4. Sharing

The app does not transmit Google user data to the developer or to any third party. Requests go directly from your machine to Google's APIs. No analytics or telemetry is sent.

5. Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not transferred to third parties, is not used for advertising, and is not read by humans except where necessary for security, to comply with law, or with your explicit consent.

6. Your choices and revocation

You can revoke the app's access at any time at myaccount.google.com/permissions. You can also delete the local credential files. After revocation, the app can no longer access your Google data.

7. Security

Credentials are kept local and scoped to the permissions you grant. The app is open source, so you can review exactly what it does: github.com/Martins6/google-workspace-mcp.
